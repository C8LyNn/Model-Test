# C01-19 WAVE 02 — four furniture prototypes
Owned P19-05 two-seat bench, P19-06 folding wall table, P19-07 medical bed, P19-08 sink, **not** any ship architecture.
All base geometry is actual OBJ triangles with UV0 and normal records, 3 orthographic-style SVG previews per model and machine-readable source JSON.
Dimensions: P19-05 W1.40 D0.55 H0.94, P19-06 W1.10 D0.65 H0.78, P19-07 W0.95 D2.20 H0.90, P19-08 W0.80 D0.57 H1.15 (m).
Materials: 4 shared material families steel / dark / fabric / accent. Floor models y=0, wall-mounted models rear z=0.
P19-06 has separate hinge at local [0,.065,-.052]; P19-07 has separately movable back section with hinge [0,.75,.45].
Native .blend, .fbx, PNG can be generated by GitHub Actions C01-19 Wave02 workflow, then files and SHA validated; do NOT treat existence of source generator as execution.
Unity: menu Tools/C01/Build furniture Wave 02 creates individual Unity prefabs with URP/Lit materials and compound primitive colliders. Requires real Unity 6 URP import, physical clearance and independent C01-02 acceptance.
Never alter the ship master prefab/scenes or merge before independent QA.
