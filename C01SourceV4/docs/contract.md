# v4 shared manifest / C# contract

Namespace `C01.Ship.V4`. Runtime assembly `C01ShipV4.Runtime`, references Unity.InputSystem. Every model is a convex XZ prism assembly; no import dependency on v3 meshes is necessary. Reuse original model geometry by copying source part definitions into the v4 models array.

Manifest: `Assets/C01ShipV4/Data/ship_v4.json`.

Top fields: version, unit=3, body=[0,63,0,45], decks [{id:0,y:-12.4},{id:1,y:0},{id:2,y:6.4}], materials[{role,color[4]}], models[{id,parts:[{role,outline:[x,z,...],y0,y1}]}], placements, zones, gates, airlocks, lifts, links, coverage.

Placement fields: id, model, category, zone, deck (int; -1 global/core), x,y,z,yaw; parent (optional lift car ID such as LIFT_BRIDGE_CAR, positions are always initial world coordinates), gate (optional gate ID for animated leaves), travel:[dx,dy,dz] (world displacement from closed to fully open), buttonGate (optional), buttonLift (optional), buttonFloor (int). Every placement remains a separate editable prefab instance. Model colliders must match full rendered details. Buttons use ShipButtonV4 with fields gateId/liftId/floor; builder resolves references.

Zone fields: id,label,kind,deck,floor,height,bounds:[x0,x1,z0,z1],waypoint:[x,y,z],parent (bathroom parent cabin, otherwise empty). IDs: L1_C01..L1_C12 and L2_C01..L2_C12; bath IDs `<cabin>_BATH`; corridors L1_MAIN_W/L1_MAIN_M/L1_MAIN_E, L1_XN1..3/L1_XS1..3, similarly L2. L0_MAIN_W/M/E. Sector IDs L1_GYM/L1_LAB/L1_MED/L1_CARGO/L1_ENGINE_CONTROL/L1_TECH; L0_ENGINE_ROOM/L0_PURIFICATION/L0_EVAC_HANGAR/L0_CARGO/L0_HYDROPONICS. Core zones L0_BRIDGE/L1_BRIDGE/L2_BRIDGE and L0_STERN/L1_STERN/L2_STERN. Height means minimum clear height; upper core galleries are 6 m, atria are taller.

Gate fields: id,deck,x,y,z,yaw,width,height,zones:[a,b],leaves:[placement IDs],buttons:[placement IDs],airlock (optional),lift (optional),floor (landing floor int). Root position is marker reference; animated leaf transforms use their initial LOCAL positions plus world travel (groups have identity rotation). Each leaf gets a kinematic Rigidbody. Public ShipGateV4: id; Transform[] leaves; Vector3[] travel; float openness (0..1), target; float speed=1.8; bool IsOpen; void SetOpen(bool); void SetImmediate(float). SetImmediate synchronizes current AND target, clamps 0..1, and physics. Must not shift a frame/node.

Airlock fields id,gates:[gateA,gateB]. ShipAirlockV4 fields ShipGateV4 gateA,gateB; void Request(ShipGateV4,bool). Only open wanted after other fully shut; cancellation/repeated requests must be safe.

Lift fields: id,car (parent marker ID),x,z,bounds:[x0,x1,z0,z1] (inner car footprint),startFloor=1,floors:[0,1,2],elevations:[-12.4,0,6.4],landings:[gate IDs],waypoints:[[landing0],[landing1],[landing2]] (outside shaft). ShipLiftV4 fields id; Transform car; ShipGateV4[] landings indexed 0..2; float[] elevations; int currentFloor=1,targetFloor=1; CharacterController player; float speed=4; bool IsMoving; void RequestFloor(int). Close all gates before moving; physically move car and carry CharacterController detected by a ground ray hitting the car; never teleport. Open landing only when stopped at target elevation. Three inner selection buttons are parented to car. A lift landing button calls RequestFloor, it does not toggle the gate independently. ResetToFloor(int) is needed for QA setup.

links: graph adjacency [{a,b,kind:'gate'|'opening'|'lift',gate:'...'}]. Lift links connect bridge or stern zones on neighboring decks and are transport abstractions, not stairs. Coverage [{id,deck,plane,normal:'up'|'down',poly:[x,z,...]}] describes independent target horizontal surface samples/polygons excluding shafts and actual crossing wall footprints. Builder must preserve data; validation casts surface rays and verifies full source geometry/positions.

Runtime markers: ShipInstanceV4 {placementId,modelId,category,zoneId;int deck}; ShipSolidV4 {modelId;int partIndex;string role}; ShipZoneV4 {zoneId,kind,label;int deck;float floor,height}. ShipExplorerV4 fields Camera view; CharacterController player; GameObject master; ShipGateV4[] gates; ShipLiftV4[] lifts; ShipButtonV4[] buttons; bool walking; int selectedDeck=1. API SetWalking(bool), SetDeck(int), ShowAll(bool), TryPressRay(Ray,float maxDistance=3.5f), ResetView(); initialize floors through ShipZone markers. Walking shows all geometry and roofs; overview hides Renderer components (never colliders) above the selected deck, hides roof/ceiling categories and upper floor slabs. Keys 1 overview,2 walking,WASD/RMB, left click physical buttons,R roof,L labels; GUI deck0/1/2/All controls. Do not retain old E-to-hinge behavior.

Editor constants: ShipV4Builder.Root='Assets/C01ShipV4'; ScenePath=Root+'/Scenes/C01_Ship_Multideck.unity'; MasterPath=Root+'/Prefabs/C01_SHIP_MULTIDECK_MASTER.prefab'; MasterName='C01_SHIP_MULTIDECK_MASTER'; QA=projectRoot+'/C01ShipV4_QA'. Read() returns ShipDataV4. Build() retains all host settings and adds ship as first build scene without removing old scenes. Export() includes v4 Assets and its source dependencies, produces QA/C01_Ship_Multideck_v4.0.unitypackage. Batch entry RebuildAndVerify for closed batch or explicit Library/ShipV4.request='rebuild' in an existing clean editor, driver acknowledgment Library/ShipV4.driver='4.0'. Run asynchronous EditMode/PlayMode tests, capture images, export only on pass; exit only in Application.isBatchMode. All fields/classes contract in ShipDataV4.cs is owned by primary; ask before changing field names.
