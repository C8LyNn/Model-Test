2. **Accept actual closed/locked render AABB** `W=0.560000002m, H=0.380000025m, D=0.341000006m` (Unity X/Y/Z), i.e. **+1.000006mm D** versus the approved P18-07 producer's 0.340m closed design depth. This is within the existing Wave02 contract's **±2mm dimensional tolerance** and does **not** relax global grid, pivots, mating sockets or ±2mm dimensional policy. The signed model need **not** be rebuilt to shave off 1mm.
3. **Mandate a separate operational reservation, not an increased nominal size:** full visible Front_Lock translation adds **+20mm along P18-07 local +Z**. Native/FBX measured 20mm-retracted render AABB: `X[-0.280000001,+0.280000001], Y[0,+0.380000025], Z[-0.170000002,+0.191000000] m`; total bounding depth `0.361000001m`. The local **+Z** protrusion (not a symmetric 361mm box) must be transformed into the placed prefab's world space before clash checks. These are visual mesh bounds, **not verified Unity PhysX collider sweeps**.
4. **Placement acceptance is CONDITIONAL and remains separate.** C01-13/C01-10 must check actual current-FBX P18-07 in each proposed non-door placement for all 11 lock travel steps 0,2,…,20mm, including external rigid meshes/colliders, object mounting, player-access corridor and no unintended obstruction. Do not infer traversability from nominal footprint alone; required minimum corridor width is an **HQ owner design decision**, not a threshold invented by C01-01.
